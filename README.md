# 🎙 Голосовые заметки

Приложение на **Streamlit** (Python 3) для ведения текстов, расстановки **маркеров**
в тексте, записи **голосовых заметок** к маркерам и **распознавания речи** в текст.

Проект работает **без базы данных** (данные хранятся в файлах) и **без контейнеризации**
(запускается локально в виртуальном окружении Python).

## Возможности

- **Папка с текстами** `data/texts/` — каждый текст отдельный Markdown-файл.
- **Вывод текстов** на страницу Streamlit через Markdown.
- **Маркеры в тексте** — инлайн-якоря вида `{{m:1}}`, в интерфейсе превращаются
  в кликабельные жёлтые метки 🔖.
- **Голосовые заметки на маркере** — запись с микрофона или загрузка аудиофайла.
- **Распознавание речи в текст** (faster-whisper) и сохранение результата как заметки.
- **Папка с записями заметок** `data/notes/` (метаданные) и `data/audio/` (аудиофайлы).
- Привязка заметок к тексту и маркеру, просмотр, редактирование, удаление, проигрывание аудио.

## Стек

- Python 3.10+
- Streamlit
- faster-whisper (распознавание речи), PyAV (декодирование аудио)
- `st.audio_input` для записи с микрофона
- Файловое хранилище (Markdown + JSON), SQLite **не используется**

## Требования

- Python 3.10 или новее
- `make` (опционально, для команд из `Makefile`)
- ~1–2 ГБ свободного диска (модель распознавания скачивается при первом запуске)
- Для записи с микрофона — браузер с доступом к микрофону (см. примечание ниже)

## Установка и запуск

```bash
make install      # создать .venv и установить зависимости
make run          # запустить приложение
```

Приложение будет доступно по адресу: **http://localhost:8501**

### Без make

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Настройки

Переменные окружения:

| Переменная         | По умолчанию | Описание                                                            |
|--------------------|--------------|---------------------------------------------------------------------|
| `WHISPER_MODEL`    | `small`      | Размер модели: `tiny`, `base`, `small`, `medium`, `large-v3`        |
| `WHISPER_LANGUAGE` | авто         | Язык распознавания, например `ru` (автоопределение, если не задано) |
| `APP_DATA_DIR`     | `./data`     | Каталог с текстами, заметками и аудио                               |

Пример:

```bash
WHISPER_MODEL=base WHISPER_LANGUAGE=ru make run
```

## Пользование

Приложение состоит из трёх вкладок.

### 📄 Тексты

- **➕ Добавить текст** — введите название и текст в Markdown.
- В тексте ставьте маркеры: `{{m:1}}`, `{{m:2}}` … (или кнопкой **➕ Добавить маркер**).
- Рендерится Markdown, а каждый маркер — кликабельная метка 🔖 с числом заметок.
- Нажмите на метку или на кнопку в списке **Маркеры**, чтобы открыть панель маркера.
- **✏️ Редактировать текст и маркеры** — правка текста, добавление маркеров, удаление текста.

### 🎙 Распознавание

1. Выберите **текст** и, при желании, **маркер** для привязки.
2. Выберите источник звука:
   - **🎙 Микрофон** — нажмите кнопку и продиктуйте заметку.
   - **📁 Файл** — загрузите аудио (`wav`, `mp3`, `m4a`, `ogg`, `flac`, `webm`).
3. Нажмите **🔍 Распознать** — речь преобразуется в текст.
4. Отредактируйте текст и нажмите **💾 Сохранить заметку**.

Тот же блок доступен прямо на маркере: откройте маркер во вкладке **Тексты** и
разверните **➕ Добавить голосовую заметку**.

### 📝 Заметки

- Фильтр: все заметки, заметки без текста или по конкретному тексту.
- **✏️ Новая текстовая заметка** — создание заметки с привязкой к тексту и маркеру.
- У каждой заметки: **Изменить** (текст и привязка), **Удалить**, проигрывание аудио.

## Структура проекта

```
.
├── app.py                    # точка входа Streamlit (интерфейс)
├── core/
│   ├── markers.py            # парсинг и отрисовка маркеров {{m:ID}}
│   ├── storage.py            # файловое хранилище (тексты, заметки, аудио)
│   └── stt.py                # распознавание речи (faster-whisper)
├── requirements.txt
├── Makefile
├── .streamlit/config.toml
└── data/                     # создаётся при запуске
    ├── texts/                # тексты (Markdown + front matter)
    ├── notes/                # заметки (JSON)
    └── audio/                # аудиозаписи голосовых заметок
```

## Хранение данных

Все данные — в каталоге `./data`:

- `data/texts/<slug>.md` — текст в Markdown с заголовком и датой в front matter;
- `data/notes/<id>.json` — заметка (текст, привязка к тексту и маркеру, путь к аудио);
- `data/audio/<id>.wav` (и др.) — аудиозаписи голосовых заметок.

Данные сохраняются между перезапусками; база данных не требуется.

## Примечание о микрофоне

Браузер разрешает доступ к микрофону только в «безопасном контексте»:
`http://localhost` либо по `https://`. При открытии приложения с другого компьютера
по `http://<IP>:8501` запись с микрофона работать не будет — используйте загрузку
аудиофайла или настройте HTTPS.
