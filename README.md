Приложение для записи голосовых заметок, с последующим анализом текста (например, распознавание речи).
Приложение должно быть реализировано с помощью библитеки Streamlit на Python 3. Проект должен быть внутри контейнера Podman или Docker

Идеи: 
- Создать БД с текстами - Рассказы, конспекты и прочее
- Создать вывод этих текстов на Streamlit черех Markdown
- Создать возможность делать заметки в тексте в аудио
- Создать распознование аудио в виде текста - текстовой заметки
- Создать БД записи заметок
- Создать вывод заметок на тексте

---

## Что реализовано

- **БД текстов и заметок** на SQLite: тексты (рассказы, конспекты) и заметки (текстовые и голосовые).
- **Вывод текстов** на страницу Streamlit через Markdown.
- **Распознавание речи в текст** (faster-whisper, модель `small`) прямо в контейнере, офлайн.
- **Запись с микрофона** или загрузка аудиофайла.
- **Привязка заметок к текстам**; просмотр, редактирование и удаление заметок, проигрывание аудио.

## Стек

- Python 3.12, Streamlit
- faster-whisper (распознавание речи), PyAV (декодирование аудио)
- audio-recorder-streamlit (запись с микрофона)
- SQLite (хранение данных)

## Требования

- Docker или Podman с compose (`docker compose` / `podman-compose`)
- `make` — для управления через `Makefile` (опционально)
- ~2 ГБ свободного диска (образ с моделью распознавания занимает ~2 ГБ)
- Для записи с микрофона — браузер с доступом к микрофону (см. примечание ниже)

## Установка и запуск

### Вариант 1. Docker Compose (рекомендуется)

```bash
docker compose up -d --build
```

Приложение будет доступно по адресу: **http://localhost:8501**

### Вариант 2. Docker напрямую

```bash
docker build -t svfu-streamlit:latest .
docker run -d --name svfu-streamlit \
  -p 8501:8501 \
  -v "$(pwd)/data:/app/data" \
  svfu-streamlit:latest
```

### Вариант 3. Podman

```bash
podman build -t svfu-streamlit:latest .
podman run -d --name svfu-streamlit \
  -p 8501:8501 \
  -v "$(pwd)/data:/app/data:Z" \
  svfu-streamlit:latest
```

### Управление контейнером

```bash
docker logs -f svfu-streamlit     # логи
docker stop svfu-streamlit        # остановить
docker start svfu-streamlit       # запустить снова
docker compose down               # остановить и удалить контейнер
docker compose up -d --build      # пересобрать после изменений
```

## Makefile

Все основные действия собраны в `Makefile` — команды короче и не зависят от того, что используется: Docker или Podman.

```bash
make install      # собрать образ и запустить контейнер (первый запуск)
```

Полный список команд:

| Команда          | Действие                                                        |
|------------------|-----------------------------------------------------------------|
| `make help`      | Показать список доступных команд                                |
| `make install`   | Собрать образ и запустить контейнер (первый запуск)             |
| `make build`     | Собрать образ                                                   |
| `make rebuild`   | Пересобрать образ без кэша                                      |
| `make up`        | Запустить контейнер через compose                               |
| `make down`      | Остановить и удалить контейнер (данные сохраняются)             |
| `make start`     | Запустить остановленный контейнер                               |
| `make stop`      | Остановить контейнер                                            |
| `make restart`   | Перезапустить контейнер                                         |
| `make logs`      | Показать логи в реальном времени (follow)                       |
| `make ps`        | Показать статус контейнера                                      |
| `make shell`     | Открыть shell внутри контейнера                                 |
| `make health`    | Проверить доступность приложения                                |
| `make test`      | Запустить smoke-тест приложения внутри контейнера               |
| `make clean`     | Удалить контейнер (данные и образ сохраняются)                  |
| `make clean-data`| Удалить данные приложения (БД и аудио)                         |
| `make clean-image`| Удалить образ                                                  |
| `make uninstall` | Полное удаление: контейнер, данные и образ                      |

### Использование с Podman

По умолчанию `Makefile` работает с Docker. Для Podman передайте `ENGINE`:

```bash
make install ENGINE=podman
make up ENGINE=podman
make uninstall ENGINE=podman
```

Можно также переопределить compose-команду или имена:

```bash
make up COMPOSE="podman compose"
make logs CONTAINER=my-notes
make up IMAGE=svfu-streamlit:v2 PORT=9000
```

## Настройки

Переменные окружения задаются в `docker-compose.yml` (секция `environment`) или в `docker run -e`:

| Переменная          | По умолчанию | Описание                                                             |
|---------------------|--------------|----------------------------------------------------------------------|
| `WHISPER_MODEL`     | `small`      | Размер модели: `tiny`, `base`, `small`, `medium`, `large-v3`         |
| `WHISPER_LANGUAGE`  | авто         | Язык распознавания, например `ru` (автоопределение, если не задано)  |
| `APP_DATA_DIR`      | `/app/data`  | Каталог с БД и аудиофайлами                                          |

Модель `small` уже вшита в образ. Другие размеры скачиваются при первом запуске (нужен интернет), поэтому для смены модели надёжнее изменить значение и пересобрать образ.

## Пользование

Приложение состоит из трёх вкладок.

### 📄 Тексты

- Разверните **«➕ Добавить текст»**, введите название и текст (поддерживается Markdown) и нажмите **Сохранить**.
- Выберите текст в списке — он отобразится с отрендеренным Markdown.
- Кнопка **🗑 Удалить текст** удаляет текст вместе с привязанными заметками и их аудио.

### 🎙 Распознавание

1. Выберите источник звука:
   - **🎙 Микрофон** — нажмите кнопку, продиктуйте текст; запись остановится автоматически после паузы.
   - **📁 Загрузить файл** — загрузите аудио (`wav`, `mp3`, `m4a`, `ogg`, `flac`, `webm`).
2. При необходимости выберите документ в поле **«Привязать к документу»**.
3. Нажмите **🔍 Распознать** — речь будет преобразована в текст.
4. Отредактируйте распознанный текст и нажмите **💾 Сохранить заметку**.

### 📝 Заметки

- Фильтр по документу или показ только свободных заметок.
- **✏️ Новая текстовая заметка** — создание заметки вручную, с привязкой к документу.
- У каждой заметки: **Изменить** (правка текста и привязки), **Удалить**, проигрывание аудио для голосовых заметок.

## Структура проекта

```
.
├── app.py                    # точка входа Streamlit (интерфейс)
├── core/
│   ├── db.py                 # работа с SQLite (тексты и заметки)
│   ├── stt.py                # распознавание речи (faster-whisper)
│   └── storage.py            # сохранение/удаление аудиофайлов

├── Dockerfile
├── docker-compose.yml
├── Makefile
├── .streamlit/config.toml
└── data/                     # монтируется в контейнер: notes.db и audio/
```

## Хранение данных

Все данные — в каталоге `./data` (монтируется в контейнер как `/app/data`):

- `data/notes.db` — база данных SQLite;
- `data/audio/` — аудиофайлы голосовых заметок.

Данные сохраняются между перезапусками и пересборками контейнера.

## Примечание о микрофоне

Браузер разрешает доступ к микрофону только в «безопасном контексте»: `http://localhost`, либо по `https://`. При открытии приложения с другого компьютера по `http://<IP>:8501` запись с микрофона работать не будет — используйте загрузку файла или настройте HTTPS.
